## 🎂 Features & Highlights

- **Artisanal Patisserie Aesthetic (Zero Purple Policy)**:
  - Designed around warm cream (`#FFF9F2`), fresh strawberry pink (`#F5A5B8`), raspberry accent (`#C9365B`), golden butter yellow (`#FFE7A3`), pistachio cream (`#B8D4A5`), and deep cocoa typography (`#382722`).
  - No purple, violet, or generic AI gradients.
- **Mobile-First Experience**:
  - Sticky bottom quick action bar on mobile devices (Instant Call, WhatsApp chat, and Order Cake CTA).
  - Touch-friendly menus, responsive drawer navigation, and accessible tap targets (>48px).
- **Interactive 3D Cake Customizer / Builder**:
  - Lets customers choose cake base flavor, size/weight (0.5kg up to multi-tier), 100% eggless / pure-veg guarantee, frosting styles, and live typed piped message on cake illustration with real-time indicative pricing.
- **Filterable Cake Catalogue (`/cakes`)**:
  - Instant search by cake name, flavor, or celebration keyword.
  - Category filters: Birthday Cakes, Signature Feather Wings, Weddings & Tiers, Celebrations, Custom Art & 3D, and 100% Pure Veg Specials.
  - Sorting by Featured, Rating, and Price.
- **Full-Screen Lightbox Gallery (`/gallery`)**:
  - Editorial masonry grid with category filters.
  - Full-screen lightbox with next/previous controls, keyboard navigation (Left/Right arrow, Escape to close), mobile swipe, and direct enquiry CTA.
- **Cake Detail Pages (`/cakes/:slug`)**:
  - High-res photo gallery with zoom modal, preparation lead times, dietary notes, flavor options, and related cake recommendations.
- **Enquiry & Order Flow (`/contact`)**:
  - Validated form with custom reference code generation (`MCD-2026-XXXX`).
  - Confetti celebration upon enquiry submission.
  - One-tap WhatsApp order sharing with pre-formatted cake specifications.
  - **Live Reference Code Tracker**: Customers can look up their enquiry code anytime to check baker status.
- **Customer Reviews & Google Reviews Gateway (`/reviews`)**:
  - Verified 5.0 Google score showcase with verified reviews (Pragnya, Amrita Priyadarshini, Prangya Panda, etc.).
  - "Leave a Google Review" flow with copyable feedback suggestions and direct Google Maps link.
- **Baker's Management Dashboard (`/admin`)**:
  - Protected Baker portal with demo PIN `2455` or `admin`.
  - Filter and manage enquiries by status: `NEW`, `CONTACTED`, `CONFIRMED`, `COMPLETED`, `ARCHIVED`.
  - Add internal baker notes and update site announcement banner.
  - Export enquiries to JSON.
- **Firebase Ready**:
  - Includes `firestore.rules`, `storage.rules`, `firebase.json`, and `.env.example` adhering to PRD Sections 10–13.

## 🚀 Quick Start

### 1. Development Server
```bash
npm install
npm run dev
```
Open your browser at `http://localhost:5173`.

### 2. Production Build
```bash
npm run build
```
Creates an optimized, minified production bundle in `dist/`.

### 3. Lint Check
```bash
npm run lint
```
